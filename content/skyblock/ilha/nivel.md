O **nível da ilha** mostra o quanto sua ilha evoluiu no SkyBlock. Esta página explica o **IS Value**, o **IS Level**, quais blocos realmente contam para o nível e até quantas unidades cada um é considerado.

## IS Value

O **IS Value** é o valor calculado pelo sistema para os **blocos válidos** presentes na sua ilha. Ele está diretamente relacionado à progressão da ilha e é exibido no jogo através do menu `/is value`.

![Menu /is value](/is-value.png)

*Menu `/is value` — consulte o valor dos blocos considerados pelo sistema.*

## IS Level

O **IS Level** representa a **progressão da ilha**. Ele aumenta conforme a ilha possui blocos que são **reconhecidos pelo sistema de nível**.

Não é qualquer bloco do Minecraft que aumenta o nível da ilha: existem **blocos específicos** configurados para contribuir com o nível, listados abaixo.

### Destaque: Note Block

> 🎵 **Note Block — limite de 10.000**
>
> O **Note Block** é o bloco musical e é uma das principais formas de trabalhar o aumento do nível da ilha: o sistema permite uma quantidade muito maior desse bloco (**até 10.000 unidades**) do que dos demais.

### Limites

O **limite** representa a quantidade máxima daquele bloco que é considerada pelo sistema para a progressão do nível. Por exemplo:

**Note Block — 10.000** significa que o sistema considera até **10.000 Note Blocks** para essa finalidade.

> **Importante:** se um bloco não estiver listado nesta página, ele **não conta** para o nível da ilha.

## Consultar o Nível

Veja o nível da sua ilha com:

```
/island level
```

Ou, para consultar o nível de outro jogador:

```
/island level <jogador>
```

## Ranking

Acompanhe as ilhas com maior nível usando:

```
/island top
```

O comando permite acompanhar as ilhas com maior nível do servidor. Veja também a página [Rankings](/skyblock/rankings) para acompanhar os tops do servidor.

> Os valores exatos de nível são exibidos no jogo.
