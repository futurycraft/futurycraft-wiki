Nosso servidor possui uma **Textura Oficial** que permite que os jogadores tenham itens personalizados e tenham uma experiência aprimorada em diversas partes do jogo.

O uso da textura é **obrigatório** — sem ela, os itens novos não aparecem corretamente no jogo!

## Como usar a textura na versão Bedrock

Na versão Minecraft Bedrock, a textura já é **baixada automaticamente** ao entrar, não é preciso fazer mais nada.

## Como usar a textura na versão Java

### 1. Selecionar e editar o servidor

Selecione o servidor da FuturyCraft na sua lista de servidores e clique em **Editar**.

### 2. Habilitar pacotes de recursos

Na tela seguinte, clique na opção **Pacotes de recursos** até que ela fique marcada como **"Sim"**.

### 3. Concluir

✅ Pronto! A textura foi ativada e basta você entrar novamente no servidor que ela será baixada automaticamente.

## Como ver a textura de armaduras

O Minecraft padrão não nos permite modificar a textura das armaduras enquanto elas estão no corpo dos jogadores, somente a versão do item no inventário quando não equipado.

Na versão **Bedrock**, infelizmente ainda não é possível ver as texturas. Mas no **Minecraft Java**, basta seguir as opções abaixo.

Para que os jogadores consigam ver a textura das armaduras quando colocadas no corpo, é necessário usar **UM** dos mods abaixo:

### Usando o mod OPTIFINE

Para um tutorial de como instalar o OPTIFINE (Forge), clique [AQUI](https://www.youtube.com/watch?v=w7T9wpaF5SY&ab_channel=Grildor).

> É importante sempre instalar a versão mais atualizada do mod. Se não conseguir instalar pelo tutorial mencionado, pode usar qualquer outro tutorial ou método.

Se preferir, também existe uma versão do Optifine para Fabric, você pode vê-la clicando [AQUI](https://www.curseforge.com/minecraft/mc-mods/optifabric).

### Usando o mod CIT RESEWN

O mod **CIT RESEWN** é uma boa alternativa para aqueles que usam o **Fabric**. Este mod é focado em somente adicionar a possibilidade de ver as texturas personalizadas.

> No momento em que este tutorial foi escrito, o mod parou seu desenvolvimento na versão 1.20.1. Verifique a versão mais atual clicando [AQUI](https://modrinth.com/mod/cit-resewn/versions#all-versions). Caso o mod não tenha sido atualizado, recomendamos optar pelo Optifine (Forge) ou OptiFabric (Fabric).

✅ Usando qualquer um dos mods acima você já será capaz de visualizar as texturas de armaduras personalizadas! (Basta usar apenas **UM** dos mods)
