Chegou no servidor e já está logado? Boa! Vamos aos primeiros passos.

## Abra o Menu Principal

Use o comando `/menu` para abrir o menu principal do servidor. É pelo menu que você acessa a maioria dos sistemas.

### Comandos iniciais

- `/menu` — abre o menu principal
- `/ajuda` — lista de comandos de ajuda
- `/warp ajuda` — teleporta para a sala de ajuda
- `/shop` — abre a loja do servidor

## Ative a Textura

Os itens novos do servidor só aparecem corretamente com a **textura oficial**. Ative com:

```
/textura
```

> Sem a textura, os itens personalizados não aparecem corretamente no jogo.

## Escolha Onde Começar

Quando estiver pronto, crie sua ilha no **SkyBlock** e comece a construir o seu império:

```
/criarilha
```
